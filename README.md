# Project Web Programming : Banana Split

### Members :

Tom GARRIDO
Antonin LE CLANCHE

### Topic :

Banana Split is a website created to be an help to find and share recipes for cocktails.

### Definition :

With Banana Split, we want to give to the user the possibility to search for different cocktail recipe with the ingredients he have at home. He also could share what recipe he do for himself and then receive some feedback from other users. Whether he uses this website to search or share, the recipes will be detailed step by step with all the potentially important information to ensure understanding and the result.
